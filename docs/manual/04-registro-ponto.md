# Registro de ponto

O ponto é batido **pelo leitor de digital**, não por login no sistema — o funcionário passa o dedo no leitor (na máquina única ou no kiosk da portaria) e o sistema registra sozinho.

## Ciclo do dia

Cada passada de dedo avança o funcionário para a próxima etapa do dia, nesta ordem:

1. **Entrada**
2. **Saída Almoço**
3. **Retorno Almoço**
4. **Saída**

Depois da **Saída**, a próxima passada de dedo começa um novo ciclo (novo dia).

## Consultar o ponto de um funcionário

Na página do funcionário, botão **Registros de Ponto**, ou menu **Relatórios** para o **Registro de Entrada e Saída** geral (todos os funcionários).

Para navegar mês a mês, use **Calendário de Presença** (escolha o funcionário e o mês).

## Pontos pendentes de revisão

*Só visível para perfil Master.*

Se um funcionário ficar muito tempo com um ciclo "aberto" (ex.: esqueceu de bater a saída), o sistema fecha automaticamente esse registro e marca como **pendente de revisão** — aparece em **Pontos Pendentes** no menu. Um `master` revisa e corrige manualmente o horário ali.

## Corrigir um ponto errado

Registros de ponto não podem ser editados diretamente (mesmo por um `master`) — a correção passa pela tela de **Pontos Pendentes**, que existe exatamente para isso. Se o ponto está errado mas não aparece como pendente, fale com quem administra o sistema.
